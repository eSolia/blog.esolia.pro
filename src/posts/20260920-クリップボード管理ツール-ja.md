何かをコピーする。次に別のものをコピーする。最初にコピーしたものは、もう消えている。誰もが一度は経験したことがあるはずです。しかも気づくのは、たいてい取り返しがつかなくなった2秒後です。

<!--more-->

## クリップボード管理ツールとは

クリップボード管理ツールは、コピーした内容の履歴を残してくれます。少し前にコピーしたものにさかのぼって貼り付けられる、というわけです。筆者はMacでMaccyというツールを使っています。軽くて速く、いつでもキー一つで呼び出せます。「Windowsだと何を使えばいいですか」とよく聞かれるので、知っておく価値のあるものをまとめました。

{{ comp.icon({ name: "keyboard", size: 4, color: "sky" }) -}}**まずは標準機能のWin + Vから**

実はWindowsには最初から入っています。意外と知られていません。**Win + V**を押すと、クリップボードの履歴が表示されます。無効になっている場合は、初回に有効化を促されますので、そのまま進めてください。**設定 › システム › クリップボード**からでも設定できます。

費用はかからず、インストールも不要。Microsoftアカウントでサインインしていれば、複数の端末で同期もされます。履歴の件数は少なく、検索機能も弱いのですが、多くの方にはこれで十分です。何かを導入する前に、まず試してみてください。

{{ comp.icon({ name: "clipboard-text", size: 4, color: "sky" }) -}}**Ditto：Maccyにいちばん近い選択肢**

Win + Vでは物足りないなら、[Ditto](https://ditto-cp.sourceforge.io/){target="_blank" rel="noopener"}をおすすめします。無償のオープンソースで、長年使われてきた実績があります。やるべきことをきちんとやってくれるツールです。検索できる長い履歴、ずっと残しておけるピン留め、そしてキーボードだけで完結する操作性。

Microsoft Storeから、またはwingetでインストールできます。

```
winget install Ditto.Ditto
```

見た目は古く感じるかもしれません。そこは正直なトレードオフで、美しさよりも確実さと速さを取ったツールです。

{{ comp.icon({ name: "arrows-left-right", size: 4, color: "sky" }) -}}**CopyQ：複数のOSを使い分けるなら**

[CopyQ](https://hluk.github.io/CopyQ/){target="_blank" rel="noopener"}もオープンソースで、Windows・macOS・Linuxに対応しています。どの端末でも同じツール、同じ操作感で使いたい方に向いています。タブやタグ、スクリプトにも対応しており、項目をその場で編集することもできます。

Dittoに比べると、初期設定に少し手間がかかります。複数のOSを行き来する方には価値がありますが、そうでなければ機能過多かもしれません。

{{ comp.icon({ name: "magic-wand", size: 4, color: "sky" }) -}}**PowerToys：置き換えではなく、補完として**

Microsoftの[PowerToys](https://learn.microsoft.com/ja-jp/windows/powertoys/){target="_blank" rel="noopener"}には**Advanced Paste**という機能があります。Win + Vの上に乗る形で、書式なしテキストやMarkdownとして貼り付けられるようになります。結局いちばん使うのは「書式なしで貼り付け」でしょう。Webページからコピーしたときに、頼んでもいない書式がついてくるのを防げます。

クリップボード管理ツールの代わりではなく、組み合わせて使うものです。標準の履歴機能との相性も良好です。

> [!IMPORTANT]
> クリップボードの履歴には、コピーした内容がそのまま平文でディスクに保存されます。パスワード管理ツールからコピーしたパスワードも、お客様情報も、その日に扱ったものはすべて含まれます。

## 導入する前に、ひとつ考えておきたいこと

便利さは本物です。そして、そこに伴うリスクも本物です。クリップボード管理ツールは、コピーしたすべての記録そのものであり、その多くは暗号化されていません。

どのツールを選ぶにせよ、次のことはやっておく価値があります。

* パスワード管理ツールを履歴から除外する設定があるか確認し、有効にする。たいていのツールには用意されています。
* 履歴を何日分残すかを決め、短めに設定する。
* 画面共有の前や、端末を誰かに渡す前に履歴を消す。
* お客様の情報を扱う業務であれば、記録を残すツールを入れる前に社内のルールを確認する。

これはクリップボード管理ツールを避ける理由ではありません。初期設定のまま使うのではなく、意識して設定してから使う理由です。

## まとめ

まずは**Win + V**を試してください。すでに入っています。もっと欲しくなったら、Windowsでは**Ditto**が素直な選択です。複数のOSで同じものを使いたいなら**CopyQ**。書式なし貼り付けには**PowerToys**を足しましょう。

そのうえで設定画面を開いて、「何を覚えさせないか」を決めてください。
